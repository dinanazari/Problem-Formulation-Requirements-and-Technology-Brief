# Cross-Modal Semantic Alignment using Vision-Language Models for Out-of-Context Misinformation Detection

## Project Summary
This project proposes a web-based misinformation detection system using Contrastive Language-Image Pre-training (CLIP) and Natural Language Processing (NLP) techniques to analyse semantic consistency between news images and their accompanying captions or headlines.

## Problem Statement
Existing text-based misinformation detection approaches may analyse textual content without considering its semantic relationship with accompanying images. This creates challenges in detecting out-of-context misinformation, where genuine images are paired with misleading captions or headlines.
